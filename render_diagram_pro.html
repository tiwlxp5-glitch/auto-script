Production Architecture

Auto Script System Flow

แผนผังสถาปัตยกรรมระบบ Serverless & Dual-AI

01
Client Layer (Frontend)
React 19 + React Router v7
  • User Interaction: ผู้ใช้งานเลือกสูตรจิตวิทยาและยิงคำขอสร้างสคริปต์
  • SSG Prerendering: โหลดหน้าเว็บรวดเร็วภายในเวลา < 50ms
  • Resilience: มีระบบ lazyWithRetry ป้องกันหน้าขาว และ AbortController ดักค้าง 60s
ส่งคำขอสร้างสคริปต์ (HTTPS POST)
02
Edge Serverless (API)
Cloudflare Pages Functions
  • Zero Cold Start: API ทำงานบน V8 Isolates กระจายตัวทั่วโลก ลาเทนซีต่ำ
  • Content Moderation: ล้าง Zero-Width Chars และกรองคำต้องห้ามก่อนส่งเข้า AI เพื่อประหยัด Token
  • Idempotent Webhooks: ป้องกันการอัปเดตสถานะและเติมเครดิตซ้ำซ้อนจาก Stripe
ตรวจสอบสิทธิ์ & หักเครดิตแบบ Atomic
03
Security & Database
Supabase (PostgreSQL 15)
Atomic RPC
  • ฟังก์ชัน increment_credits ล็อคแถวระดับฐานข้อมูลทันที
  • ป้องกันปัญหา Race Condition (แฮกกดเบิ้ล)
Data Protection
  • Row Level Security: คุมสิทธิ์แยกข้อมูลผู้ใช้ 100%
  • pg_cron: ลบสคริปต์เก่าอัตโนมัติ (3 หรือ 30 วัน)
เครดิตเพียงพอ ➔ ส่งวิเคราะห์เนื้อหา
04
AI Processing Engine
Google Gemini Dual-Engine
Gemini 3.6 Flash
  • โหมดมาตรฐาน (PAS, HSO, FOMO, 3-Version)
  • สร้างบทพูดธรรมชาติ มีจังหวะหายใจ (...)
  • เน้นความรวดเร็วและคุ้มค่า Token
Gemini 3.1 Pro Preview
  • โหมดเจาะลึก (Belief-Shifting)
  • ใช้ Chain of Thought (CoT) เพื่อการใช้เหตุผล
  • วิเคราะห์กลไกและจิตวิทยาเชิงลึกก่อนร่างบทพูด
ปรุงสคริปต์เสร็จ ➔ บันทึกประวัติและจัดส่ง
05
Delivery & Failsafe
System Integrity
  • Symmetric Refund: หาก AI ขัดข้อง หรือ Database บันทึกไม่สำเร็จ ระบบจะคืนเครดิตกลับทันที 100% ป้องกันผู้ใช้ถูกหักเครดิตฟรี
  • Discord Alerts: ยิงแจ้งเตือนฟีดแบ็กและบั๊กเข้าห้อง Admin แบบเรียลไทม์ พร้อม AI สรุปรายงานรายสัปดาห์
