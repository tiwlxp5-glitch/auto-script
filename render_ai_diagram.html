AI Prompt Engineering Architecture

Auto Script AI Brain

เบื้องหลังวิศวกรรม Prompt และการสร้างเนื้อหาจิตวิทยา

01
Input Processing & Moderation
Data Sanitization
  • Thai Obfuscation Detection: ระบบล้าง Zero-Width Chars และช่องว่าง เพื่อป้องกันการหลบเลี่ยงคำหยาบ
  • Competitor Filter: ดักจับคำโจมตีคู่แข่ง (เช่น "กาก", "ขยะ") และแจ้งเตือนให้ใช้ภาษาเชิงบวกก่อนยิงเข้า AI
ข้อมูลปลอดภัย ➔ เตรียมสวมบทบาท
02
Dynamic Persona Engine
Micro-Persona System
Contextual Roles
  • Micro-Persona: AI สวมบทบาทให้เข้ากับสินค้า (เช่น "เพื่อนสาวจอมแฉ", "ผู้เชี่ยวชาญ", "แม่ค้าฮาร์ดเซลล์")
Speaker Tone Alignment
  • Gender Context: ปรับสรรพนามและน้ำเสียงให้ตรงเพศ (ชาย/หญิง) อย่างเป็นธรรมชาติ
กำหนดคาแรคเตอร์ ➔ เริ่มกระบวนการคิด
03
Cognitive Processing
Gemini Dual-Engine
Standard Engine (Speed)
  • Gemini 3.6 Flash: ใช้ Temperature 0.85 เพื่อความสร้างสรรค์ เน้นโครงสร้าง PAS / HSO / FOMO ที่รวดเร็วและแม่นยำ
Pro Deep Brain™ PRO TIER
  • Chain of Thought (CoT): เจาะลึกจิตวิทยา Epiphany Bridge วิเคราะห์อารมณ์ลูกค้าก่อนแต่งสคริปต์จริงผ่าน gemini-3.1-pro-preview
กระบวนการคิดเสร็จสิ้น ➔ เกลาสำนวนภาษา
04
Language & Anti-Repetition
Dynamic Prompting
Hook Strategy Engine
  • Abstract Concepts: ดึง 6 โครงสร้าง Hook จากคลัง 40+ แบบ ป้องกันปัญหา AI แต่งคลิปซ้ำซาก (Anti-Repetition)
Negative Constraints
  • Strict Rules: ห้ามใช้คำเชยๆ (เช่น "เคยป่ะ", "ใครกำลัง") และบังคับให้เว้นจังหวะหายใจ ("...") ให้เหมือนมนุษย์
จัดรูปแบบเป็น JSON ➔ ส่งกลับไปยัง API
05
Output Validation
Structure Failsafe
  • Structured JSON Schema: บังคับให้ AI ต้องคืนค่ากลับมาในรูปแบบ script_blocks และ metadata ตามที่กำหนดเท่านั้น
  • safeParseJson (Backend): ระบบซ่อมแซมและตรวจสอบชนิดของข้อมูล (Array/String) โดยอัตโนมัติ เพื่อป้องกันไม่ให้หน้าเว็บแครช (UI Breakage)
