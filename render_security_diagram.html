Data Security & Privacy Architecture

Auto Script Security Shield

แผนผังระบบรักษาความปลอดภัยของข้อมูลส่วนบุคคลและธุรกรรมทางการเงิน

01
Access & Network Shield
Cloudflare CORS & Auth
  • CORS Policy & DoS Protection: อนุญาตเฉพาะโดเมนแท้ ตัดข้อความยาวเกินดักจับ Memory Exhaustion (DoS)
  • Auth Hardening: บังคับรหัส 8 ตัว ป้องกัน Email Enumeration (สุ่มหาอีเมล) และยืนยันตัวตนผ่าน Resend SMTP
ตรวจสอบ Token ข้ามไปยัง Serverless API
02
Backend API Firewall
Edge Functions Security
RPC Lockdown AUDITED
  • Service Role Guard: ปิดกั้นการเจาะฐานข้อมูลตรงจากหน้าเว็บ API เป็นด่านตรวจสิทธิ์ชั้นแรก 100%
Prompt Injection Guard
  • XML Enclosure: ห่อหุ้มข้อมูลผู้ใช้ใน <user_comment> ป้องกันการแฮ็กหลอกข้ามคำสั่ง AI
ผ่านการกรอง ➔ สั่งการระบบจัดการเครดิต
03
Database & Isolation
Supabase Row Level Security
Row Level Security (RLS)
  • 100% Data Isolation: กั้นกำแพงข้อมูล ผู้ใช้ไม่สามารถอ่าน หรือมองเห็นสคริปต์ของคนอื่นได้เด็ดขาด
Concurrency Safety
  • Race Condition Guard: บัญชีเครดิตทำงานแบบ Atomic ป้องกันการกดรัวๆ (Double Spend) เพื่อโกงเครดิต
เชื่อมต่อระบบชำระเงินภายนอก (Stripe)
04
Payment & Financial Security
Stripe Webhooks & Ledger
Backend-Only Validation
  • Trust No Client: การเลื่อนขั้นแพ็กเกจ (Tier) จะถูกอัปเดตผ่านหลังบ้านจาก Stripe โดยตรง ป้องกันการปลอมแปลงบิล
Idempotency System
  • Replay Attack Prevention: ดักจับ Event ID หากเกิดการยิงซ้ำ (Retry) ป้องกันการแจกเครดิตเบิ้ล
วัฏจักรข้อมูล & สิทธิส่วนบุคคล (PDPA)
05
Data Privacy & Lifecycle
Data Protection Standards
  • Auto-Cleanup (pg_cron): ระบบลบสคริปต์ของบัญชีฟรีอัตโนมัติใน 3 วัน ลดภาระพื้นที่และไม่เก็บข้อมูลค้างเกินจำเป็น
  • Full CASCADE Deletion: หากผู้ใช้ขอลบบัญชี ระบบจะล้างประวัติ ทรานแซคชัน และสคริปต์ทั้งหมดแบบถอนรากถอนโคน เพื่อเคารพสิทธิความเป็นส่วนตัว (Right to be Forgotten)
